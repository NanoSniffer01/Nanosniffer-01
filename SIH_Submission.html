Supervisory Analytics Tool for SOC Assessment (SAT-SA)

Smart India Hackathon (SIH) Portal Submission Document

1. Problem Statement / Domain

Domain: Cybersecurity / NCIIPC

Challenge: Monitoring and assessing the security posture, operational efficiency, and execution gaps of Security Operations Centers (SOCs) across multiple Critical Sector Entities (CSEs) is highly fragmented. Supervisors lack a centralized, real-time analytics platform to benchmark entities, prioritize critical alerts, and enforce compliance dynamically.

2. Proposed Solution / Idea

We propose SAT-SA—a centralized, high-performance web dashboard designed specifically for cybersecurity supervisors.

SAT-SA acts as a single pane of glass that ingests data from various SOCs across critical sectors (Energy, Finance, Healthcare). It instantly processes this data to generate risk distributions, highlight architectural execution gaps, and provide real-time benchmarking between entities. By leveraging an intuitive, data-driven UI, supervisors can rapidly identify vulnerabilities, track escalation rates, and generate automated compliance dossiers.

3. Key Features & Methodology

  • Real-Time Analytics Dashboard: Interactive data visualizations (Donut, Area, and Bar charts) that track critical alerts, findings by category, and risk distribution across all supervised entities.
  • Entity Risk Profiling & Drawers: A highly interactive entity management system. Supervisors can click on any CSE to open a "mini-dossier" drawer containing immediate risk badges and recent findings without losing context of the global table.
  • Execution Gap Tracking: A dedicated module to track "Negative Space" and execution failures, categorizing them by severity (High, Critical, Low) and confidence scores.
  • Automated PDF Report Generation: Built-in client-side engine to instantly generate and download multi-page, confidential PDF reports (e.g., "Execution Gap Report") for offline auditing and executive briefings.
  • Resilient API Architecture: A fault-tolerant service layer that features a "Graceful Fallback Mode" ensuring the dashboard remains operational during backend downtimes.

4. Technology Stack

  • Frontend: React.js 18, TypeScript, Vite
  • UI & Styling: Tailwind CSS, Lucide Icons
  • Data Visualization: Recharts (D3.js based)
  • Reporting & Export: jsPDF
  • API & Networking: Axios, RESTful API
  • Backend: Python / FastAPI (REST API)

5. Use Cases & Target Audience

  • Target Audience: National Cyber Security Supervisors, NCIIPC Auditors, CISOs, and SOC Managers.
  • Use Case 1 (Benchmarking): A supervisor wants to compare the incident response time of the Finance sector against the Energy sector to identify systemic weaknesses.
  • Use Case 2 (Auditing): An auditor requires an immediate physical report of all "Critical" execution gaps discovered in the last 30 days to present to stakeholders. SAT-SA generates this PDF in one click.

6. Unique Selling Proposition (USP)

Unlike traditional, clunky log-management tools, SAT-SA focuses purely on Supervisory Analytics. It abstracts away raw terminal data and transforms it into actionable, executive-level insights. Its resilient API design ensures 100% uptime for supervisors, while the zero-latency frontend provides an unparalleled, frictionless user experience for critical decision-making.
